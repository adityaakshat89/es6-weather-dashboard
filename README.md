# Weather Dashboard
A straightforward weather web app built with Vanilla JavaScript. I put this together to get hands-on practice with modern ES6 syntax and handling REST API requests, keeping things lightweight without relying on frontend frameworks.

## Tech Stack
* HTML & CSS
* Vanilla JavaScript (ES6+)
* Open-Meteo API (for live weather data)

## ES6 Concepts Applied
Instead of older JS patterns, this project specifically focuses on modern implementation:
* Handled asynchronous network requests using `async / await` and Promises.
* Kept functional logic clean using Arrow Functions.
* Used Object Destructuring to parse specific data points from complex JSON API responses.
* Handled dynamic DOM manipulation using Template Literals.

## How to run locally
Because this is built with standard HTML/JS, there are no dependencies, node modules, or build steps required. 
Just clone the repository and open the `.html` file directly in your browser.
